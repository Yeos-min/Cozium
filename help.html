이용 안내

Cozium은 바탕화면에 쌓인 파일을 방바닥의 물건처럼 집어 상자에 담으며 정리하는 웹 게임입니다. 같은 종류끼리 모인 더미를 한 번에 집고, 폴더가 된 상자에 넣습니다.

시작하는 세 가지 방법 파일과 개인정보 조작법 자주 묻는 질문 알아 둘 점

시작하는 세 가지 방법

샘플로 체험내 파일로 체험Desktop Helper 연결
준비없음바탕화면에서 CtrlA로 고른 뒤 끌어다 놓기내 컴퓨터에서 Helper 실행
읽는 것미리 준비된 가상 파일내가 놓은 파일과 폴더바탕화면 폴더
실제 파일그대로그대로. 정리 결과는 계획으로만 남음상자에 넣는 순간 실제로 옮겨짐
바로 가기체험해 보기내 파일로 시작하기정리방에서 연결하기

데스크톱 Chrome과 Edge에서 동작합니다. 내 파일을 가져오는 기능은 다른 브라우저와 휴대폰에서는 쓸 수 없습니다.

파일과 개인정보

어디로도 보내지 않습니다
Cozium에는 파일을 받는 서버가 없습니다. 웹 체험에서 읽은 파일 정보(이름, 크기, 종류, 수정 시각)와 사진 미리보기는 지금 열린 브라우저 탭의 메모리에서만 쓰이고, 탭을 닫거나 새로고침하면 사라집니다.
남기지 않습니다
쿠키, 브라우저 저장소, 방문 분석 도구를 쓰지 않습니다. 회원가입과 로그인도 없습니다.
웹 체험은 읽기만 합니다
끌어다 놓은 파일은 읽기만 하고 디스크에는 아무것도 쓰지 않습니다. 웹페이지가 바탕화면 전체를 스스로 열어 볼 수는 없고, 내가 골라서 놓은 항목만 읽습니다.
Desktop Helper를 쓸 때

Helper는 내 컴퓨터 안(127.0.0.1)에서만 열리는 작은 프로그램입니다. 실행할 때마다 새 접속 토큰을 만들고, Cozium 사이트에서 온 요청만 받습니다. 사이트에는 파일의 실제 경로를 보내지 않습니다.

하는 일은 세 가지입니다. 바탕화면 폴더 안에서 파일 옮기기, 새 폴더 만들기, 방금 옮긴 것 되돌리기. 삭제 기능은 없고, 옮길 곳에 같은 이름의 파일이 있으면 덮어쓰지 않고 그 파일만 건너뜁니다.

페이지를 닫거나 15분 동안 요청이 없으면 스스로 꺼집니다. 되돌리기 기록은 이번 접속 동안만 남고, 새로고침하면 사라집니다. 파일은 옮긴 자리에 그대로 있습니다.

사이트 접속 기록
공개 주소는 GitHub Pages로 제공합니다. 페이지를 불러올 때 생기는 접속 기록은 GitHub가 처리하며, GitHub 일반 개인정보처리방침을 따릅니다.

조작법

첫 화면

휠, 스와이프, 방향키(↓ Space / ↑) 한 번에 다음 장면까지 재생됩니다. 바닥의 파일 더미를 누르면 더미 전체가 손에 모이고, 상자를 누르면 들어갑니다. 더미 네 개를 모두 넣으면 정리된 바탕화면으로 넘어갑니다. 멈춘 장면에서 스크롤만 계속하거나 Enter를 누르면 시연이 재생됩니다.

정리방

첫 클릭으로 시점을 잡고, Esc로 마우스를 놓습니다.

마우스 / WASD, 방향키둘러보기 / 걷기
파일 클릭, 누른 채 훑기파일 한 개 또는 여러 개 집기
폴더 클릭 / 1–9들고 있는 파일 넣기
빈손으로 폴더 클릭폴더 열기
오른쪽 클릭보고 있는 자리에 내려놓기
CtrlZ마지막으로 넣은 묶음 되돌리기
Tab파일 정리 / 상자 배치 전환
상자 배치 중 휠상자 돌리기

자주 묻는 질문

바탕화면 폴더를 통째로 고를 수는 없나요?

Chrome이 보안을 위해 바탕화면, 문서, 사용자 폴더 자체는 웹페이지에 넘기지 못하게 막아 둡니다. 대신 바탕화면에서 CtrlA로 항목을 모두 고른 뒤 끌어다 놓으면 됩니다. 휴지통이나 내 PC 같은 항목은 빠질 수 있습니다.

파일을 지울 수도 있나요?

없습니다. Cozium은 옮기고 분류하는 일만 합니다. Helper에도 삭제 기능이 없습니다.

잘못 넣었어요.

CtrlZ로 마지막에 넣은 묶음을 되돌립니다. 새로고침하기 전까지 여러 번 되돌릴 수 있습니다.

정리한 결과를 실제 바탕화면에 반영하려면요?

웹 체험은 계획만 남깁니다. 실제로 옮기려면 정리방에서 Desktop Helper를 연결하세요. 연결할 때 Chrome이 ‘로컬 네트워크 접근’을 물으면 허용합니다.

왜 3D 방에서 정리하나요?

같은 종류끼리 공간에 모여 있으면 덩어리가 한눈에 보여서 시작하기 쉽고, 손으로 집어 옮기는 감각이 목록에서 고르는 것보다 덜 귀찮기 때문입니다.

알아 둘 점

  • Cozium은 수업 과제로 만든 시제품입니다. 기능과 화면은 계속 바뀔 수 있습니다.
  • Helper로 실제 바탕화면을 정리하기 전에는 중요한 파일을 백업해 두세요. 처음에는 연습용 폴더로 해 보길 권합니다.
