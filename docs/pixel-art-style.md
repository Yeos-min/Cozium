# 1인칭 픽셀 아트 실험 · 2026-10-09

사용자 승인: 공식 데모에 더 가까워지도록 **1인칭은 유지하고 나머지 시각 요소를 변경**한다. 정사영 구도 버전은 이번 1인칭 결과를 확인한 뒤 후속 실험으로 남긴다. 이 문서는 이번 구현 설명이며 최종 디자인 확정 기록은 아니다.

## 현재 설정

`js/three/tuning.js`의 `pixelation`은 화면 CSS 기준 `pixelSize=6`, `normalEdgeStrength=0.5`, `depthEdgeStrength=0.6`이다. 콘솔 `__tuning.pixelation` 변경은 다음 프레임에 반영된다. wrapper가 실제 renderer DPR을 곱해 공식 pass에 넘기므로 high/low 품질·고밀도 화면에서도 같은 화면 크기로 비교한다. 내부 target은 정수 크기이므로 창 크기에 따라 실제 블록 폭은 조금 달라질 수 있다.

`pixelArt`에는 면 음영(`flatShading`), 단순 침대(`primitiveBed`), 바닥 타일 두 색(`floorColors`)과 반복 길이(`floorRepeat`)가 있다. 해당 제작 설정과 조명·재질 변경은 파일을 저장하고 페이지를 새로고침해 확인한다. `pixelArt.enabled=false`만으로 이전 색·조명까지 복구되는 것은 아니다. 완전한 이전 구현은 백업 파일을 사용한다.

## 변경 내용

- 기존 나뭇결 바닥을 작은 nearest 샘플링 체크 타일로 교체. 질감 흐림과 mipmap·anisotropy를 제거한다.
- 벽은 차가운 청색, 목재는 적갈색·금색, 식물과 장식은 더 선명한 지정 색으로 변경. `pixel-art-style.js`의 `PROP_COLORS`는 기존 장식 색을 명시적으로 교체하는 표다. 화면 전체 색을 양자화하지 않는다.
- ACES 톤매핑과 안개·벽 물감 번짐·투명한 햇빛 얼룩 제거. NoToneMapping, 따뜻한 주광, 차가운 환경광, BasicShadowMap으로 면과 그림자를 분리한다.
- 재질은 무광·flat shading으로 설정. 공식 r185 pass의 normal material도 같은 flat shading을 사용한다. 공식 addon 소스는 수정하지 않는다.
- 장식 가구는 같은 크기의 각진 상자, 원통은 최대 8면으로 변경. 침대 GLB는 이번 스타일에서 기존 프리미티브 침대로 대체한다. GLB 파일·로더는 보존하며 `primitiveBed=false`로 저장 후 새로고침하면 원래 침대를 불러올 수 있다.
- 액자 그림은 48×64에서 그려 nearest 샘플링한다. 파일 카드와 상자 텍스처도 nearest로 표시하고, 문서 카드의 종류 색 표시와 모서리 대비를 강화한다. 실제 사진 미리보기의 정보·파일명·크기 표시는 유지한다.

Color Quantization과 Dithering은 추가하지 않았다. Kuwahara·기존 외곽선은 최초 픽셀 버전처럼 기본 off/0이며 코드와 UI는 남아 있다.

## 유지한 동작과 한계

원근 1인칭 카메라, 위치·FOV·감도·이동 속도·손의 위치·스프링 수치, 방과 파일 배치의 크기·좌표·충돌 발자국, 파일 집기/넣기/되돌리기, HTML/CSS UI를 유지했다. 카메라 위치를 픽셀 단위로 강제 이동하는 보정은 추가하지 않았다. 1인칭에서는 가까운 물체가 커지고 움직일 때 픽셀 경계가 바뀌는 원근 특성이 남는다. 작은 모델 글자는 6px 픽셀에서 덜 읽히며 기존 HTML hover 라벨로 확인한다.

`output/pixel-art-20261009/`의 before/after 캡처는 같은 1440×900 화면·seed=123·1인칭 시점·6px·edge 0.5/0.6으로 비교한다. 따라서 색·질감·모델 변경과 픽셀 크기 변경을 혼동하지 않는다. 브라우저 검증 JSON과 활성 테스트 로그, 실제 반영·백업 위치는 작업 타임라인에 기록한다.

## 정사영 비교 설정 · 2026-10-09

오른쪽 위 톱니바퀴 → 카메라 → **정사영**으로 전환한다. 기본 진입은 계속 **1인칭**이며 같은 메뉴에서 돌아온다. 정사영은 실제 `THREE.OrthographicCamera`를 사용해 거리에 따른 원근 축소를 없애고, 방 전체를 비스듬히 내려다본다. 앞쪽·오른쪽 벽과 걸레받이만 열어 내부를 보여주며 1인칭 복귀 시 복원한다. 기존 사선/탑다운 비교 모드도 유지한다.

`TUNING.camera.orthographic`의 `elevation`(높이 각도), `azimuth`(좌우 각도), `fit`(화면 여백)을 조절한다. 시작값은 35.264° / 45° / 1.08이다. `fit`을 줄이면 확대된다. 현재 열린 벽은 시작 구도를 기준으로 앞·오른쪽이다. resize 시 방의 모서리를 카메라 공간에 투영하여 가로·세로 비율에 맞춰 다시 잡는다. RenderPixelatedPass와 기존 필터·레이캐스트·HTML 라벨은 선택된 카메라를 공유한다.

정사영에서는 기존 사선 모드와 같은 커서 클릭 조작을 사용하고 WASD 걷기는 1인칭에서 사용한다. 카메라 전환 시 폴더 위치는 기존 전환 규칙(1인칭 먼 쪽, 비교 모드 아래쪽)을 따른다. 정사영 캡처·검증은 `output/orthographic-20261009/`에 보관한다.
