## 눈으로 본 문제 (Claude 진단 — 사용자 확인 전)

1. **"누르는 큰 버튼"이 화면마다 다른 물건이다.** 랜딩 「시작해볼까요?」 = 크림 테두리 + 반투명 유리, 999px. 시작 화면 「방에 들어가기」 = 연노랑 채움, 10px. 가져오기·결과 「방으로 가기 / 방으로 돌아가기」 = 진녹색 채움(`.win-go`). 내비 「정리방 들어가기」 = 크림 칩, 7px. 같은 역할 4가지 모양.
2. **판(재질)이 섞여 있다.** 크림 종이 창(가져오기·결과 `#fffaf0` 계열), 반투명 갈색 유리(버튼·문구 판·건너뛰기), 진갈색 막대(내비 `#463529`), 어두운 녹회색 카드(시작 화면), 초록 테두리 칩(배치 모드). 무엇이 "창", 무엇이 "안내", 무엇이 "버튼"인지 재질로 안 갈린다.
3. **두 기본색이 경쟁한다.** 갈색 베이스 `#463529`·`#2f231a`와 녹색 잉크 `#254c43`(랜딩 27번, 가져오기·결과의 주 버튼). 사용자가 10-18에 CTA를 녹색에서 분리했지만 앱 쪽은 아직 녹색.
4. **한글에 목소리가 없다.** 로고만 Fraunces라 인상이 있고, 한글 문구는 전부 시스템 고딕 → 어떤 문구든 "시스템 메시지"로 읽힌다. 10-23 문구 판이 촌스러워 보인 가장 큰 원인으로 본다.
5. **안내 문법이 화면마다 다르다.** 랜딩은 가운데 큰 판, 앱 방은 아래 키캡 줄 + 아래 안내 띠, 시작 화면은 표, 결과는 창 안 문장.
6. 작은 글자가 많다(위 숫자).

## 새 채팅에서 정할 것 (제안 순서)

1. 한글 글꼴 — 제목용·본문용(웹폰트 용량, 라이선스, 주아를 어디까지 쓸지. 랜딩 주아 금지는 지금까지의 규칙 — 다시 정할지 물을 것).
2. 재질 2~3가지와 역할(예: 종이 = 알려 줌 / 유리 = 누름 / 진갈색 = 사이트 틀). 밤 방·낮 방·노트북 화면 세 배경 위에서 다 읽혀야 한다.
3. 색 토큰 — 갈색과 녹색 중 무엇이 주인인지, 강조색(노랑 `#d9b768`?) 하나.
4. 글자 크기 단계(6~7단계), 최소 크기.
5. 버튼 한 벌(주·보조·글자 링크), 문구 판·안내 띠·칩 한 벌.
6. 움직임 규칙(나타남·사라짐·누름), 동작 줄이기.
7. 말투(존댓말 「~해요」 통일? 지금 섞여 있지 않은지 확인).

정해지면 `docs/design-system.md` 앞부분을 이 기준으로 새로 쓰고, CSS는 공용 토큰 파일 하나(`css/tokens.css` 같은)로 모으는 것을 제안 — **구현은 사용자가 정한 뒤**.
