# Jua (배달의민족 주아체)

- `Jua-ks.woff2` — Jua Regular, 한글 KS X 1001 2,350자 + 영문·숫자·기본 문장부호만 남긴 것(196 KB).
  출처: Google Fonts의 Jua(npm `@fontsource/jua` 5.3.0의 나뉜 파일 88개를 하나로 합친 뒤 fontTools로 줄임, 2026-10-18).
- 라이선스: SIL Open Font License 1.1 (`OFL.txt`). 상업적 사용·수정·재배포 가능, 폰트 자체 판매만 금지.
- 쓰는 곳: "다 치웠어요!" 정도 크기의 한글 제목(사용자 2026-10-18). `css/onboarding.css`·`css/help.css`의 `--heading`.
  작은 본문·로고(Cozium)에는 쓰지 않는다.
- KS X 1001에 없는 드문 글자(예: 똠, 쀍)는 기본 글꼴로 보인다. 제목 문구를 바꿀 때만 신경 쓰면 된다.
